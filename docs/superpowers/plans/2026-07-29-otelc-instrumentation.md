# OpenTelemetry Compile-Time Instrumentation (otelc) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire OpenTelemetry compile-time auto-instrumentation (`otelc`) across all `thump` beat binaries (`clank`, `hiss`, `rattle`, `thump`, `trim`) without breaking local development, IDEs (`gopls`), linters (`golangci-lint`), `Taskfile.yaml`, `Dockerfile`, or `.goreleaser.yml`.

**Architecture:** Maintain a clean `go.mod` on `main` without hardcoded local `./.otelc-build/` `replace` directives. Pin dependencies and the `otelc` tool in `go.mod` (Go 1.24+ `tool` tracking) and `otel.instrumentation.go`. Execute `go generate ./otel.instrumentation.go` and `go tool otelc go build` dynamically inside build targets (`Taskfile`, `Dockerfile`, `GoReleaser`).

**Tech Stack:** Go 1.26, OpenTelemetry `otelc` (`github.com/open-telemetry/opentelemetry-go-compile-instrumentation`), Taskfile, Docker, GoReleaser v2.

## Global Constraints

- **Non-Interference**: Standard `go test ./...`, `go build ./...`, `gopls`, and `golangci-lint` must succeed on a fresh git checkout without pre-generated folders or special environment variables.
- **Go Mod Invariant**: `go.mod` committed to git must never contain unresolvable local `./.otelc-build/` replace directives.
- **GOFLAGS Syntax**: Never use space-separated or single-quote embedded strings inside `GOFLAGS` (e.g. `GOFLAGS='-toolexec=...'`), which fails Go's env var parser.

	_ "go.opentelemetry.io/otelc/instrumentation/google.golang.org/grpc/server"

### Task 2: Update Taskfile.yaml with `otelc` Build Targets

**Files:**
- Modify: `Taskfile.yaml:30-60`

**Interfaces:**
- Consumes: `otel.instrumentation.go` and `go tool otelc`
- Produces: `task otelc:prep` and updated `task build`

- [ ] **Step 1: Modify `Taskfile.yaml` to add `otelc:prep` and `build` instrumentation**

Update `Taskfile.yaml` to include:
```yaml
  otelc:prep:
    desc: Run otelc pin generate to create transient instrumentation wrappers
    cmds:
      - go generate ./otel.instrumentation.go

  build:
    desc: Build all beat binaries into bin/ with otelc instrumentation
    deps: [otelc:prep]
    cmds:
      - mkdir -p bin
      - for:
          var: BEATS
        cmd: go tool otelc go build -ldflags "{{.LDFLAGS}}" -o bin/{{.ITEM}} ./cmd/{{.ITEM}}
```

- [ ] **Step 2: Verify `task build` builds instrumented binaries**

### Task 3: Update Dockerfile for `otelc` Compile-Time Instrumented Containers

**Files:**
- Modify: `Dockerfile:1-24`

**Interfaces:**
- Consumes: `go generate ./otel.instrumentation.go`
- Produces: Instrumented container images for `SERVICE_BEATS` and `JOB_BEATS`

- [ ] **Step 1: Update `Dockerfile` build stage**

```dockerfile
FROM --platform=$BUILDPLATFORM golang:1.26 AS deps
WORKDIR /src
COPY go.mod go.sum ./
RUN go mod download

FROM deps AS build
ARG BEAT
ARG VERSION=dev
ARG COMMIT=none
ARG DATE=unknown
ARG TARGETOS
ARG TARGETARCH
COPY . .
RUN go generate ./otel.instrumentation.go
RUN CGO_ENABLED=0 GOOS=$TARGETOS GOARCH=$TARGETARCH go tool otelc go build -ldflags "-s -w \
    -X main.version=${VERSION} \
    -X main.commit=${COMMIT} \
    -X main.date=${DATE}" -o /out/${BEAT} ./cmd/${BEAT}

FROM gcr.io/distroless/static-debian12:nonroot
LABEL org.opencontainers.image.source="https://github.com/ianeff/thump"
ARG BEAT
COPY --from=build /out/${BEAT} /usr/local/bin/beat
ENTRYPOINT ["/usr/local/bin/beat"]
```

- [ ] **Step 2: Test building container image locally using docker build**

Run: `docker build --build-arg BEAT=thump -t thump-test:local .`  
Expected: Successful Docker build.
